# 0.7.0 — 2026-10-31

## Added

- **`epa_superfund_get_site`** retrieves exact SEMS site metadata and every contaminant association; `epa://superfund/{site_id}` adds `contaminants` alongside its existing top-level site fields. Associations do not establish current exposure or concentrations. ([#58](https://github.com/cyanheads/epa-mcp-server/issues/58))
- **`epa-guide` skill resource** connects facility compliance, TRI releases, and neighborhood screening workflows, with identity, reporting-period, coverage, and availability checks.

## Changed

- **Coordinate inputs** require a complete Superfund latitude/longitude/radius triple and valid geographic bounds in Superfund and AirNow, including coordinates supplied alongside an AirNow ZIP. Remove partial triples and out-of-range coordinates before upgrading. ([#55](https://github.com/cyanheads/epa-mcp-server/issues/55))
- **Packaging and startup** include published skills in npm, Docker, and MCPB; add Agent Plugins manifests; retain runtime skill modules while removing dependency agent documents; load Node `.env` before optional AirNow registration.
- **Tool text** preserves upstream Markdown characters, line breaks, and enrichment notices as literal data on both response surfaces.

## Removed

- **`cleanupStatus`** is removed from Superfund site records; consume optional `nonNplStatusName`, `archivedInd`, `epaId`, and `federalFacilityInd` instead, without interpreting assessment labels as cleanup progress. `exclude_archived` defaults to false. ([#57](https://github.com/cyanheads/epa-mcp-server/issues/57))

## Fixed

- **Superfund listed searches** match SEMS `F,A` codes; add deleted, removed, and withdrawn filters and return the source NPL label. ([#50](https://github.com/cyanheads/epa-mcp-server/issues/50))
- **Broad proximity searches** exhaust a bounded candidate scan before distance ordering and limiting, abort sibling requests on failure, and disclose coordinate coverage and omitted matches. Incomplete scans remain errors. ([#54](https://github.com/cyanheads/epa-mcp-server/issues/54))
