# 0.3.0 — 2026-07-10

## Added

- **`epa_get_ejscreen`** — tool returning EJScreen environmental-justice indicators for a point and surrounding buffer (default 1 mile, capped at 15). Reports the 13 environmental indicators (PM2.5, ozone, diesel particulate, NO2, lead paint, traffic proximity, Superfund/RMP/hazardous-waste/wastewater proximity, underground storage tanks, drinking-water non-compliance, RSEI toxic air releases) and 6 demographic indicators (people of color, low income, limited English, less than high school, under 5, over 64), each with national and state percentiles plus EJ Index values, along with the Demographic Index and Supplemental Demographic Index. Points outside US coverage return a coverage note instead of fabricated indicators. ([#12](https://github.com/cyanheads/epa-mcp-server/issues/12))
- **`src/services/ejscreen/`** — service wrapping the community-maintained EJAM API (`api.ejanalysis.com`, Public Environmental Data Partners), which rehosts EJScreen v2.2 (2022) after EPA discontinued public access in 2025. Keyless; not a live EPA endpoint.
- **`EJSCREEN_API_BASE_URL`** — optional environment variable overriding the EJScreen (EJAM) API base URL (default `https://api.ejanalysis.com`); wired into `server.json` and `manifest.json`.
