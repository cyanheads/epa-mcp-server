# 0.3.1 — 2026-08-22

## Changed

- **MCP protocol** — adopts `@cyanheads/mcp-ts-core` ^0.12.3 and MCP SDK v2: modern MCP protocol support, undeclared tool input fields are rejected, and error results advertise a validation-compatible envelope.
- **Packaging** — updates the Bun build images and package manager pin to 1.4.0, and removes platform-specific native bindings from MCPB bundles.

## Fixed

- **`epa_search_tri_releases`** batches facility IDs to avoid oversized URLs and respects `limit`.
- **`epa_search_violations`, `epa_search_facilities`, and `epa_search_water_systems`** honor `limit` while preserving full-match totals where the upstream exposes them.
