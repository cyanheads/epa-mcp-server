# 0.5.0 — 2026-10-18

## Changed

- **DMAP request-line limits:** all-years facility TRI sorting adds 88 bytes; combined Superfund city/proximity searches add latitude predicates (47 bytes for 47.6/-122.3/25 miles). Near-limit filters previously returning correct empty results can now reject; shorten filters or specify a TRI `year`.

## Fixed

- **`epa_search_superfund`** retrieves latitude-prefix candidates for coordinate searches, retains other filters, and applies exact distance filtering; reaching the shared 500-candidate cap warns on both response surfaces, including empty results. ([#43](https://github.com/cyanheads/epa-mcp-server/issues/43))
- **`epa_get_tri_releases`** orders omitted-year filings newest first with deterministic submission ties and discloses its 500-filing cap on both response surfaces, with narrowing guidance that preserves punctuation-scan notices. ([#44](https://github.com/cyanheads/epa-mcp-server/issues/44))
- **TRI empty-result guidance** recommends a changed accepted call based on supplied filters and removes unreachable `no_releases_found` declarations; empty results remain successful. ([#45](https://github.com/cyanheads/epa-mcp-server/issues/45))

## Dependencies
