# 0.4.1 — 2026-10-16

## Added

- **`epa_get_facility`** returns `triFacilityIds` for `epa_get_tri_releases` ([#31](https://github.com/cyanheads/epa-mcp-server/issues/31)), `programCompliance` (per-statute status, inspections, actions, penalties), `triReleasesTransfersYear`, `inspectionsTotal`, and `county`/`fipsCode` ([#36](https://github.com/cyanheads/epa-mcp-server/issues/36), [#37](https://github.com/cyanheads/epa-mcp-server/issues/37), [#40](https://github.com/cyanheads/epa-mcp-server/issues/40)).
- **`notice`** on `epa_get_facility` and `epa://facility/{registry_id}` when ECHO's facility status lookup fails, on `epa_search_violations` when a filing-date range leaves criminal cases out, and on `epa_search_tri_releases`, `epa_get_tri_releases`, and `epa_search_superfund` when a punctuated text filter may have more matches ([#28](https://github.com/cyanheads/epa-mcp-server/issues/28), [#36](https://github.com/cyanheads/epa-mcp-server/issues/36), [#41](https://github.com/cyanheads/epa-mcp-server/issues/41)).

## Changed

- **`epa_get_facility`** reads ECHO's `get_dfr` report plus one best-effort `get_facility_info` row instead of calling three endpoints ECHO does not serve; inspections are the newest 100 of the last five years, and program flags key on the ECHO system ([#36](https://github.com/cyanheads/epa-mcp-server/issues/36), [#37](https://github.com/cyanheads/epa-mcp-server/issues/37)).
- **An unknown registry ID** fails after one request as `facility_not_found` (NotFound), where it was retried four times as an upstream outage; an ECHO `QueryID … not found` also stops after one request ([#35](https://github.com/cyanheads/epa-mcp-server/issues/35)).
- **`epa_search_facilities`** and **`epa_search_violations`** fail with an InternalError naming the filter when ECHO does not apply one they sent ([#28](https://github.com/cyanheads/epa-mcp-server/issues/28), [#38](https://github.com/cyanheads/epa-mcp-server/issues/38)).
- **`epa_search_facilities`** rows carry real per-program flags and five-year inspection and penalty totals; `has_violation` keeps facilities in significant noncompliance ([#38](https://github.com/cyanheads/epa-mcp-server/issues/38)).
- **`epa_search_tri_releases`** without `year` returns the newest reporting year first ([#33](https://github.com/cyanheads/epa-mcp-server/issues/33)).
- **Every tool call** runs under one deadline shared by its requests and retries (50 s for DMAP calls and `epa_get_facility`, 55 s for AirNow and EJAM, 58 s for ECHO searches); expiry is a Timeout with `reason: retry_deadline_exceeded` ([#42](https://github.com/cyanheads/epa-mcp-server/issues/42)).

## Fixed

- **`epa_search_facilities`** `state`, `city`, `has_violation`, and `programs` reach ECHO under names it honors, so a state-wide search no longer fails and filters no longer drop silently; `programs` with more than one entry is rejected, since ECHO filters on one ([#38](https://github.com/cyanheads/epa-mcp-server/issues/38)).
- **`epa_search_violations`** sends its date, ZIP, program, and `case_type` filters under ECHO's documented names. Rejected: a date not in `YYYY-MM-DD` form or not a calendar day (`2024-02-30`), `date_filed_start` after `date_filed_end`, and `case_type: "criminal"` with a date bound ([#28](https://github.com/cyanheads/epa-mcp-server/issues/28)).
- **`epa_get_tri_releases`** and **`epa_search_tri_releases`** with `include_release_breakdown` split the breakdown request to fit DMAP's request-line limit, so a facility with many filings no longer fails ([#39](https://github.com/cyanheads/epa-mcp-server/issues/39)).
- **`chemical_name`, `county`, and `city`** match commas, apostrophes, brackets, and Greek letters as written instead of failing as an upstream outage, and drop end slashes. Rejected before any request: text with no letter or digit, text over 4,094 characters, and exact-value filters (such as `facility_id`) holding a character DMAP cannot match ([#41](https://github.com/cyanheads/epa-mcp-server/issues/41)).
